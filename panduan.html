Apa itu SISPA?

SISPA (Sistem Informasi Supervisi Pendidikan Akademik) adalah aplikasi berbasis web untuk memudahkan kepala sekolah dan pengawas dalam melaksanakan supervisi akademik dan coaching kepada guru.

Siapa penggunanya?

Peran Fungsi Utama
Kepala Sekolah (KS) Mengelola data guru, melakukan supervisi (LK1), dan coaching (LK2) di sekolahnya sendiri
Pengawas Sekolah Memantau hasil supervisi & coaching di sekolah binaan, melihat tren, dan analisis
Admin Mengelola user, sekolah, pengaturan aplikasi, dan backup data

Cara Login

  1. Buka https://onelabszz.github.io/sispa/
  2. Masukkan NPSN sekolah Anda (untuk KS) atau NPSN khusus (untuk Pengawas/Admin)
  3. Masukkan password — default: sama dengan NPSN
  4. Klik Masuk
Password default = NPSN. Setelah login pertama kali, disarankan untuk mengganti password agar lebih aman.

Struktur Aplikasi

Setiap halaman memiliki komponen yang sama:

  • Sidebar Kiri — menu navigasi utama (klik ikon ☰ di HP untuk membuka)
  • Header Atas — menampilkan NPSN dan nama sekolah
  • Area Konten — halaman yang sedang dibuka
  • Tombol Keluar — ikon 🚪 di sidebar bawah untuk logout

Akses dari HP

Aplikasi dapat diakses dari smartphone. Tampilan akan otomatis menyesuaikan ukuran layar. Untuk navigasi, gunakan tombol ☰ (menu) di kiri atas.

1. Mengatur Profil

Lengkapi profil Anda terlebih dahulu — data ini akan muncul di kop laporan PDF.

  1. Buka menu Dashboard
  2. Klik tombol Edit Profil di kanan atas kartu biru
  3. Isi:
    • Nama Lengkap & Gelar — mis. Dra. Siti Aminah, M.Pd
    • NIP — 18 digit
    • Pangkat / Golongan — mis. Pembina/IV a
    • Jabatan — biasanya Kepala Sekolah
    • Status Kepegawaian — PNS / PPPK / Non ASN
    • Jenis Kelamin — L / P
    • No. HP — format 08xxxxxxxxxx
    • Email — untuk notifikasi
  4. Klik Simpan
Penting: Data profil ini akan muncul di semua laporan PDF yang Anda cetak. Isi dengan benar sesuai data kepegawaian resmi.

2. Mengelola Data Guru

Sebelum supervisi, pastikan data guru sudah lengkap.

Menambah Guru Satu per Satu

  1. Buka menu Data Guru di sidebar
  2. Klik tombol + Tambah Guru
  3. Isi form:
    • NIP (opsional, tapi disarankan diisi)
    • Nama Lengkap — wajib
    • Mapel — mis. Matematika
    • Kelas — mis. V
    • Email
    • Status Kepegawaian — PNS / PPPK / Non ASN
  4. Klik Simpan

Import CSV Massal

Kalau guru banyak (>10), gunakan impor CSV.

  1. Klik tombol Impor CSV
  2. Klik Unduh Template untuk mendapatkan contoh format
  3. Isi file CSV di Excel/Sheets
  4. Klik Pilih File CSV atau paste langsung di textarea
  5. Amati preview, klik Impor Sekarang

Format CSV:

NIP, Nama, Mapel, Kelas, Email, Status 198501012010011001, Budi Santoso S.Pd, Matematika, V, budi@sch.id, PNS 198502022011012002, Siti Aminah S.Pd, IPA, VI, siti@sch.id, PPPK

3. Melakukan Supervisi

Supervisi = kunjungan kelas untuk menilai pembelajaran digital menggunakan instrumen LK1 (19 indikator).

Memulai Supervisi

  1. Buka menu Supervisi
  2. Pilih guru dari daftar kartu
  3. Klik Mulai Supervisi
  4. Isi identitas:
    • Tanggal supervisi
    • Mapel yang disupervisi
    • Materi yang diajarkan
    • Durasi pelajaran (menit)

Mengisi 19 Indikator

Setiap indikator diberi skor 1–4:

SkorArti
1Belum Terlihat
2Mulai Terlihat
3Berkembang
4Mahir

Klik tombol angka di kanan setiap indikator. Tambahkan catatan bukti observasi di kolom bawah.

Indikator Terbagi dalam 6 Area

  • A — Perencanaan dan Kesiapan Pembelajaran Digital (3 indikator)
  • B — Pemanfaatan Platform dan Media Digital (3 indikator)
  • C — Interaksi dan Keterlibatan Murid (4 indikator)
  • D — Literasi Digital dan Etika (3 indikator)
  • E — Asesmen Berbasis Digital (3 indikator)
  • F — Pengelolaan Kelas Digital (3 indikator)

Catatan Kualitatif

Isi 4 kotak catatan:

  • Kekuatan / Praktik Baik — apa yang sudah bagus
  • Area Pengembangan — apa yang perlu diperbaiki
  • Rencana Pembinaan — langkah tindak lanjut
  • Catatan Tambahan — info lain

Menyimpan

  • Simpan Draft — kalau belum selesai, bisa lanjut nanti
  • Simpan & Kirim — kirim ke pengawas. Setelah ini tidak bisa diubah
Perhatian: Setelah dikirim ke pengawas, form menjadi read-only (tidak bisa diubah). Pastikan semua data sudah benar sebelum klik "Kirim".

4. Melakukan Coaching

Coaching = percakapan dengan guru setelah supervisi menggunakan metode STAR–GROW.

Metode STAR (4 indikator)

  • S — Situation: menggali konteks
  • T — Task: menggali tujuan
  • A — Action: menggali tindakan
  • R — Result: menggali hasil

Metode GROW (4 indikator)

  • G — Goal: tujuan pengembangan
  • R — Reality: kondisi nyata
  • O — Options: opsi/alternatif
  • W — Will: komitmen tindak lanjut

Langkah Coaching

  1. Buka menu Coaching
  2. Pilih guru dari kartu
  3. Isi tanggal
  4. Isi skor 8 indikator (1–4)
  5. Isi catatan kekuatan dan area pengembangan
  6. Isi RTL (Rencana Tindak Lanjut):
    • Rencana Aksi
    • Waktu Pelaksanaan
    • Dukungan yang Diperlukan
    • Indikator Keberhasilan
  7. Klik Simpan & Kirim

5. Mencetak Laporan PDF

  1. Buka salah satu supervisi/coaching berstatus Terkirim
  2. Klik Cetak Laporan PDF di panel kanan
  3. Tab baru terbuka dengan dokumen lengkap
  4. Klik tombol Cetak / Simpan sebagai PDF
  5. Di dialog print, pilih Save as PDF
  6. Simpan file
PDF sudah dilengkapi format resmi: judul instrumen, identitas, tabel indikator, catatan kualitatif, dan kolom tanda tangan.

Panduan ini untuk Pengawas Sekolah. Login dengan NPSN khusus pengawas.

1. Dashboard Monitoring

Dashboard pengawas menampilkan ringkasan seluruh sekolah binaan.

Komponen Dashboard

  • Stat Cards — Total sekolah, guru, supervisi, rata skor
  • Chart Tren — Grafik aktivitas supervisi & coaching per bulan
  • Chart Kategori — Distribusi capaian (Mahir, Berkembang, dst.)
  • Perlu Perhatian — Daftar sekolah/guru yang butuh tindak lanjut
  • Rekap per Sekolah — Tabel semua sekolah binaan

Filter Periode

Gunakan dropdown di atas untuk memilih:

  • Semester Berjalan — Ganjil (Jul–Des) atau Genap (Jan–Jun)
  • Semester Lalu — Periode sebelumnya
  • Tahun Ajaran Penuh — Satu tahun

2. Panel "Perlu Perhatian"

Panel ini secara otomatis menyorot hal-hal yang butuh tindakan:

TipeArti
Sekolah Pasif Tidak ada supervisi terkirim dalam 1 bulan terakhir
Draft Menumpuk Ada 2+ supervisi berstatus draft belum dikirim
Guru Belum Disupervisi Ada guru yang belum pernah disupervisi periode ini

Klik tombol Lihat untuk menuju halaman terkait.

3. Melihat Detail Sekolah

  1. Di tabel rekap, klik nama sekolah atau tombol Detail
  2. Halaman baru menampilkan:
    • Info KS (nama, NIP, HP, email)
    • Statistik sekolah (jumlah guru, supervisi, rata skor)
    • Chart distribusi kategori
    • Progress guru disupervisi
    • Tabel rekap per guru

4. Daftar Guru Lintas Sekolah

  1. Klik menu Daftar Guru
  2. Lihat semua guru dari sekolah binaan
  3. Gunakan filter:
    • Cari nama/NIP
    • Filter sekolah
    • Filter status (Belum / Draft / Terkirim)
    • Filter kepegawaian (PNS / PPPK / Non ASN)
    • Sort by rata skor, nama, atau terakhir disupervisi
  4. Klik nama sekolah untuk ke detail sekolah

5. Semua Supervisi & Coaching

Lihat semua supervisi/coaching dari sekolah binaan dalam satu tabel.

  1. Klik menu Semua Supervisi atau Semua Coaching
  2. Filter berdasarkan:
    • Nama guru / sekolah
    • Sekolah
    • Status (Terkirim / Draft)
    • Kategori capaian
  3. Klik ikon 📄 untuk cetak PDF (hanya yang terkirim)
  4. Klik ikon 👁 untuk lihat detail

6. Tips Monitoring Efektif

  • Cek dashboard setiap minggu — jangan biarkan "Perlu Perhatian" menumpuk
  • Gunakan filter periode — bandingkan semester untuk melihat tren
  • Follow-up sekolah pasif — hubungi KS via WA
  • Apresiasi sekolah aktif — jadikan contoh untuk sekolah lain
  • Cetak rekap semester — untuk laporan ke dinas

Pertanyaan Umum

Bagaimana cara login pertama kali?
Gunakan NPSN sebagai username dan password. Contoh: NPSN 20512345, password 20512345.
Saya lupa password, bagaimana?
Hubungi Admin aplikasi untuk reset password. Admin akan mengubah password kembali ke NPSN.
Apakah data supervisi bisa diubah setelah dikirim?
Tidak. Setelah klik Kirim ke Pengawas, form menjadi read-only. Pastikan semua data sudah benar sebelum mengirim.
Bagaimana cara export laporan PDF?
Buka supervisi/coaching berstatus Terkirim → klik Cetak Laporan PDF → di tab baru, klik tombol cetak → pilih Save as PDF.
Apakah aplikasi bisa diakses dari HP?
Ya. Buka di browser HP (Chrome/Safari). Tampilan otomatis menyesuaikan. Untuk navigasi, klik ikon ☰ di kiri atas.
Berapa guru yang bisa disupervisi per semester?
Tidak ada batasan. Rekomendasi: setiap guru minimal 1× disupervisi per semester.
Apa perbedaan "Draft" dan "Terkirim"?
Draft — masih bisa diubah, belum terlihat pengawas.
Terkirim — sudah dikirim pengawas, tidak bisa diubah, muncul di dashboard pengawas.
Bagaimana cara import banyak guru sekaligus?
Buka menu Data Guru → klik Impor CSV → paste data atau upload file CSV. Format: NIP, Nama, Mapel, Kelas, Email, Status.
Apakah pengawas bisa melihat data sekolah lain?
Tidak. Pengawas hanya melihat sekolah binaan sesuai pengaturan admin.
Aplikasi error / tidak bisa dibuka, apa yang harus dilakukan?
  1. Refresh halaman (Ctrl+Shift+R)
  2. Buka /settings.html → Reset ke Default → Uji Koneksi
  3. Kalau masih gagal, hubungi Admin aplikasi
Apakah data aman?
Data disimpan di Google Sheets (milik dinas) dengan akses terbatas. Setiap aktivitas tercatat di audit log. Password di-hash (tidak disimpan dalam bentuk teks).

Mengatasi Masalah Umum

1. Tidak Bisa Login

Gejala: Muncul pesan "NPSN atau password salah".

Solusi:

  • Pastikan NPSN benar (8 digit angka)
  • Pastikan password default = NPSN
  • Kalau sudah pernah ganti, gunakan password baru
  • Kalau lupa, hubungi Admin untuk reset

2. Halaman Kosong / Loading Terus

Gejala: Dashboard tampil tapi data kosong, atau spinner tidak berhenti.

Solusi:

  • Tekan Ctrl+Shift+R (hard refresh)
  • Buka /settings.html → klik Uji Koneksi
  • Kalau merah, klik Reset ke Default → Simpan
  • Kalau masih gagal, tunggu 5 menit lalu coba lagi

3. Tombol "Cetak PDF" Tidak Berfungsi

Gejala: Klik tombol tapi tidak ada yang terjadi.

Solusi:

  • Izinkan popup di browser (klik ikon 🚫 di address bar)
  • Pastikan supervisi berstatus Terkirim, bukan Draft
  • Coba di browser lain (Chrome / Firefox)

4. Data Tidak Tersimpan

Gejala: Klik simpan tapi data tidak muncul.

Solusi:

  • Cek koneksi internet
  • Refresh halaman, buka ulang
  • Kalau draft, cek di daftar supervisi dengan status Draft
  • Kalau terkirim, cek di dashboard pengawas

5. Muncul Error di Console

Gejala: Halaman tampil tapi ada error merah di Console (F12).

Solusi:

  • Refresh (Ctrl+Shift+R)
  • Clear cache browser
  • Kalau berlanjut, screenshot dan hubungi Admin

6. Tidak Bisa Login Setelah Migrasi

Gejala: Baru pindah backend, tapi user tetap pakai URL lama.

Solusi:

  • Buka /settings.html
  • Klik Reset ke Default
  • Klik Uji Koneksi → pastikan hijau
  • Login ulang

7. Import CSV Gagal

Gejala: Pesan error saat impor.

Solusi:

  • Pastikan format kolom benar
  • Cek tidak ada karakter aneh (mis. tanda kutip berlebih)
  • Maksimal 500 baris per impor
  • Download template untuk contoh format

8. Sesi Berakhir Terus

Gejala: Sering diminta login ulang.

Solusi:

  • Sesi berlangsung 8 jam — normal kalau habis
  • Jangan clear browser data saat sesi aktif
  • Kalau sering, hubungi Admin
