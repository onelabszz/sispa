Apa itu SISPA?

SISPA (Sistem Informasi Supervisi Pendidikan Akademik) adalah aplikasi berbasis web untuk memudahkan kepala sekolah dan pengawas dalam melaksanakan supervisi akademik dan coaching kepada guru.

Siapa penggunanya?

PeranFungsi Utama
Kepala Sekolah (KS)Mengelola data guru, melakukan supervisi (LK1) & coaching (LK2) di sekolahnya sendiri
Pengawas SekolahMemantau hasil supervisi & coaching di sekolah binaan
AdminMengelola user, sekolah, pengaturan aplikasi, backup

Cara Login

  1. Buka https://onelabszz.github.io/sispa/
  2. Masukkan NPSN sekolah (untuk KS) atau NPSN khusus (Pengawas/Admin)
  3. Masukkan password — default: sama dengan NPSN
  4. Klik Masuk
Password default = NPSN. Setelah login pertama kali, disarankan mengganti password agar lebih aman.

Struktur Aplikasi

  • Sidebar Kiri — menu navigasi (klik ☰ di HP untuk membuka)
  • Header Atas — NPSN dan nama sekolah
  • Area Konten — halaman yang sedang dibuka
  • Tombol Keluar — ikon 🚪 di sidebar bawah untuk logout

Akses dari HP

Aplikasi dapat diakses dari smartphone. Tampilan otomatis menyesuaikan. Untuk navigasi, klik ikon ☰ (menu) di kiri atas.

Panduan ini untuk Kepala Sekolah. Login dengan NPSN sekolah Anda.

1. Mengatur Profil

Lengkapi profil Anda — data ini akan muncul di kop laporan PDF.

  1. Buka menu Dashboard
  2. Klik tombol Edit Profil di kanan atas kartu biru
  3. Isi: Nama Lengkap & Gelar, NIP, Pangkat/Golongan, Jabatan, Status Kepegawaian, Jenis Kelamin, No. HP, Email
  4. Klik Simpan
Penting: Data profil akan muncul di semua laporan PDF. Isi dengan benar.

2. Mengelola Data Guru

Menambah Guru Satu per Satu

  1. Buka menu Data Guru
  2. Klik + Tambah Guru
  3. Isi form: NIP, Nama, Mapel, Kelas, Email, Status Kepegawaian
  4. Klik Simpan

Import CSV Massal

  1. Klik tombol Impor CSV
  2. Klik Unduh Template untuk contoh format
  3. Isi file CSV di Excel/Sheets
  4. Klik Pilih File CSV atau paste di textarea
  5. Preview muncul otomatis, klik Impor Sekarang

3. Melakukan Supervisi (LK1)

Supervisi = kunjungan kelas menilai pembelajaran digital (19 indikator).

Langkah Supervisi

  1. Buka menu Supervisi
  2. Pilih guru dari daftar kartu
  3. Isi identitas: tanggal, mapel, materi, durasi
  4. Isi skor 19 indikator (skor 1–4):
    • 1 = Belum Terlihat
    • 2 = Mulai Terlihat
    • 3 = Berkembang
    • 4 = Mahir
  5. Isi catatan kualitatif (Kekuatan, Area Pengembangan, Rencana, Catatan Tambahan)
  6. Klik Simpan Draft (belum selesai) atau Simpan & Kirim
Setelah dikirim ke pengawas, form menjadi read-only — tidak bisa diubah. Pastikan data benar.

4. Melakukan Coaching (LK2)

Coaching = percakapan dengan guru setelah supervisi menggunakan STAR–GROW.

Metode STAR (4 indikator)

  • S — Situation (konteks)
  • T — Task (tujuan)
  • A — Action (tindakan)
  • R — Result (hasil)

Metode GROW (4 indikator)

  • G — Goal (tujuan pengembangan)
  • R — Reality (kondisi nyata)
  • O — Options (alternatif)
  • W — Will (komitmen)

Isi RTL (Rencana Tindak Lanjut)

  • Rencana Aksi
  • Waktu Pelaksanaan
  • Dukungan yang Diperlukan
  • Indikator Keberhasilan

5. Mencetak Laporan PDF

  1. Buka supervisi/coaching berstatus Terkirim
  2. Klik Cetak Laporan PDF
  3. Tab baru terbuka dengan dokumen lengkap
  4. Klik tombol Cetak / Simpan sebagai PDF
  5. Di dialog print, pilih Save as PDF
Panduan ini untuk Pengawas Sekolah. Login dengan NPSN khusus pengawas.

1. Dashboard Monitoring

Dashboard menampilkan ringkasan seluruh sekolah binaan.

  • Stat Cards — Total sekolah, guru, supervisi, rata skor
  • Chart Tren — Grafik aktivitas supervisi & coaching per bulan
  • Chart Kategori — Distribusi capaian (Mahir, Berkembang, dst.)
  • Perlu Perhatian — Daftar sekolah/guru yang butuh tindak lanjut
  • Rekap per Sekolah — Tabel semua sekolah binaan

Filter Periode

  • Semester Berjalan — Ganjil (Jul–Des) atau Genap (Jan–Jun)
  • Semester Lalu — Periode sebelumnya
  • Tahun Ajaran Penuh — Satu tahun

2. Panel "Perlu Perhatian"

TipeArti
Sekolah PasifTidak ada supervisi terkirim dalam 1 bulan terakhir
Draft MenumpukAda 2+ supervisi berstatus draft
Guru BelumAda guru yang belum pernah disupervisi

3. Detail Sekolah

Klik nama sekolah atau tombol Detail untuk melihat:

  • Info KS (nama, NIP, HP, email)
  • Statistik sekolah
  • Chart distribusi kategori
  • Progress guru disupervisi
  • Tabel rekap per guru

4. Daftar Guru Lintas Sekolah

Menu ini menampilkan semua guru dari sekolah binaan dalam satu tabel. Filter: nama/NIP, sekolah, status, kepegawaian.

5. Semua Supervisi & Coaching

Lihat semua supervisi/coaching dari sekolah binaan. Filter & cetak PDF yang terkirim.

6. Tips Monitoring

  • Cek dashboard setiap minggu
  • Gunakan filter periode untuk bandingkan semester
  • Follow-up sekolah pasif via WA
  • Apresiasi sekolah aktif
Panduan ini untuk Administrator Aplikasi. Hanya 1 orang yang memiliki role ini.

1. Dashboard Admin

Ringkasan sistem: total sekolah, user, guru, supervisi, coaching, aktivitas 7 hari, status sistem, distribusi per kecamatan.

2. Kelola Users

Tambah User

Menu Users → + Tambah User → isi form → Simpan.

Import CSV

Klik Impor CSV → paste/upload → preview → Impor.

Reset Password

Klik ikon 🔑 pada baris user → konfirmasi → password reset ke NPSN.

Login As (Impersonate)

Klik ikon 👤✓ → login sebagai user tersebut → banner oranye muncul untuk kembali.

Menu Aksi (⋮)

  • Nonaktifkan — soft delete
  • Aktifkan — aktifkan kembali
  • Hapus Permanen — hapus dari database

3. Kelola Sekolah

Tambah Sekolah

Menu Sekolah → + Tambah Sekolah → isi NPSN, nama, jenjang, kecamatan, dll.

Import CSV

Format: NPSN, Nama Sekolah, Jenjang, Kecamatan, Kabupaten, Provinsi, Nama KS, Alamat, Telepon, Email.

Atur Binaan Pengawas

Klik ikon 🛡 pada baris sekolah → centang pengawas → Simpan.

4. Audit Log

Lihat semua aktivitas user. Filter berdasarkan role, aksi, tanggal. Ekspor CSV.

5. Pengaturan Aplikasi

Tab Umum

Tahun ajaran aktif, semester, nama dinas, kabupaten, provinsi.

Tab Kategori

Atur kategori penilaian LK1 (0–76) & LK2 (0–32). Bisa tambah/edit/hapus.

Tab Sistem

Info versi, test koneksi, backup spreadsheet, ekspor data, bersihkan cache.

Tab Reset Data

Zona berbahaya. Menghapus data permanen. Backup dulu sebelum menggunakan.
  • Hapus Supervisi & Coaching
  • Hapus Data Guru
  • Hapus User (kecuali Admin)
  • Hapus Sekolah (kecuali Dinas)
  • FULL CLEANUP — semua data operasional

6. Backup Rutin

  • Mingguan — backup spreadsheet
  • Bulanan — ekspor CSV semua sheet
  • Semester — ekspor penuh + arsip

7. Keamanan

  • Jangan bagikan akun admin
  • Ganti password berkala
  • Pantau audit log setiap minggu
  • Simpan backup di tempat aman

Pertanyaan Umum

Bagaimana cara login pertama kali?
Gunakan NPSN sebagai username dan password. Contoh: NPSN 20512345, password 20512345.
Saya lupa password, bagaimana?
Hubungi Admin aplikasi untuk reset. Password akan dikembalikan ke NPSN.
Apakah data supervisi bisa diubah setelah dikirim?
Tidak. Setelah klik Kirim, form menjadi read-only.
Bagaimana cara export laporan PDF?
Buka supervisi/coaching Terkirim → klik Cetak Laporan PDF → klik tombol cetak → Save as PDF.
Apakah aplikasi bisa diakses dari HP?
Ya. Buka di browser HP. Tampilan otomatis menyesuaikan. Navigasi pakai ikon ☰.
Apa perbedaan "Draft" dan "Terkirim"?
Draft — masih bisa diubah, belum terlihat pengawas.
Terkirim — sudah dikirim pengawas, tidak bisa diubah.
Bagaimana cara import banyak guru sekaligus?
Menu Data Guru → Impor CSV → paste data atau upload CSV.
Apakah pengawas bisa melihat data sekolah lain?
Tidak. Pengawas hanya melihat sekolah binaan sesuai pengaturan admin.
Aplikasi error / tidak bisa dibuka, apa yang harus dilakukan?
  1. Refresh halaman (Ctrl+Shift+R)
  2. Buka /settings.html → Reset ke Default → Uji Koneksi
  3. Kalau masih gagal, hubungi Admin
Apakah data aman?
Data disimpan di Google Sheets milik dinas dengan akses terbatas. Setiap aktivitas tercatat di audit log. Password di-hash.

Mengatasi Masalah Umum

1. Tidak Bisa Login

Solusi:

  • Pastikan NPSN benar (8 digit angka)
  • Pastikan password default = NPSN
  • Kalau sudah pernah ganti, gunakan password baru
  • Kalau lupa, hubungi Admin untuk reset

2. Halaman Kosong / Loading Terus

Solusi:

  • Tekan Ctrl+Shift+R (hard refresh)
  • Buka /settings.html → klik Uji Koneksi
  • Kalau merah, klik Reset ke Default → Simpan
  • Kalau masih gagal, tunggu 5 menit lalu coba lagi

3. Tombol "Cetak PDF" Tidak Berfungsi

Solusi:

  • Izinkan popup di browser (klik ikon 🚫 di address bar)
  • Pastikan supervisi berstatus Terkirim, bukan Draft
  • Coba di browser lain

4. Data Tidak Tersimpan

Solusi:

  • Cek koneksi internet
  • Refresh halaman, buka ulang
  • Kalau draft, cek di daftar supervisi dengan status Draft

5. Muncul Error di Console (F12)

Solusi:

  • Refresh (Ctrl+Shift+R)
  • Clear cache browser
  • Kalau berlanjut, screenshot & hubungi Admin

6. Tidak Bisa Login Setelah Migrasi

Solusi:

  • Buka /settings.html
  • Klik Reset ke Default
  • Klik Uji Koneksi → pastikan hijau
  • Login ulang

7. Import CSV Gagal

Solusi:

  • Pastikan format kolom benar
  • Cek tidak ada karakter aneh
  • Maksimal 500 baris per impor
  • Download template untuk contoh format

8. Sesi Berakhir Terus

Solusi:

  • Sesi berlangsung 8 jam — normal kalau habis
  • Jangan clear browser data saat sesi aktif
  • Kalau sering, hubungi Admin
